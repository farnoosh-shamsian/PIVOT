# PIVOT — Corpus Register

**Patterns of Indirect Versions: Origins of Divergence in the Transmission of Translated Texts**

This repository holds the corpus register accompanying the PIVOT research proposal submitted to
**[FUNDER / CALL / HOST INSTITUTION — fill in]**.

[`PIVOT_corpus_register.csv`](PIVOT_corpus_register.csv) lists the 31 Persian versions that make up
the proposed corpus, grouped into four clusters:

| cluster | source work |
|---|---|
| A | Xenophon, *Cyropaedia* |
| B | Aeschylus, *Persae* |
| C | Plato, *Crito* (anchor) |
| D | New Testament, four Gospels |

Each row records the version identifier, cluster, Greek source work, translator, year, transliterated
title, publisher and place, the transmission regime (direct, indirect, or to be established), and the
role the version is proposed to play in the study.

Nothing else is published here. The register is a description of the corpus, not the corpus itself:
no translation texts are redistributed.
